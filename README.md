# Express AI (demo)
Simple static frontend + Node proxy to OpenAI.

## Local run
1. `git clone ...`
2. `cd express-ai`
3. `npm install`
4. set `OPENAI_API_KEY` in your environment
5. `npm start`
6. Open http://localhost:3000

## Deploy to Render
Follow the instructions in the project root: create a Web Service on Render, connect to this repo, set env var OPENAI_API_KEY in Render, then deploy.
